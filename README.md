# HealRx Aesthetics & Laser Clinic — Production Frontend

A high-performance, luxury medical aesthetics web application built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Three.js / React Three Fiber**.

Doctor-led, scientifically grounded, and designed for premier patient engagement in Sion, Mumbai under Medical Director **Dr. Pruthvi Vaity**.

---

## 1. Technology Stack

* **Core Framework:** React 18 + TypeScript (Strict Mode)
* **Build Tooling:** Vite 6
* **Styling & Design System:** Tailwind CSS with custom luxury palette (`ivory`, `charcoal`, `gold`)
* **Interactive 3D:** Three.js, `@react-three/fiber`, `@react-three/drei` (with progressive background loading & WebGL error boundary)
* **Animation & Motion:** Framer Motion (respects `prefers-reduced-motion`)
* **Icons:** Lucide React
* **Routing:** React Router v6 (SPA routing with Cloudflare Pages, Netlify & Vercel rewrite rules)

## 3. Quick Start & Local Development

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`. Hot Module Replacement (HMR) is active.

---

## 4. Production Build & Validation

### Build for Production
```bash
npm run build
```
This runs TypeScript project compilation (`tsc -b`) and bundles the static assets into `dist/` with optimal chunk splitting.

### Preview Production Build Locally
```bash
npm run preview
```
Spins up a lightweight local server serving the generated `dist/` folder at `http://localhost:4173`.

### Quality & Audit Scripts
```bash
# Type check all files without emitting code
npm run typecheck

# Lint source files with ESLint
npm run lint

# Run automated structural, route, slug, and security audit
npm run verify
```

## 5. Environment Variables

Create a `.env` or `.env.local` file in the project root by copying the documented `.env.example`:

```bash
cp .env.example .env
```

| Variable | Description | Default / Example |
| :--- | :--- | :--- |
| `VITE_SITE_URL` | Canonical domain for sitemaps, Open Graph, and Twitter cards | `https://healrx.in` |
| `VITE_CLINIC_PHONE` | Direct clinic phone number | `+919372164224` |
| `VITE_CLINIC_EMAIL` | Inquiries and consultation email | `contact@healrx.in` |
| `VITE_CLINIC_WHATSAPP` | WhatsApp number in international format | `919372164224` |

> **Security Note:** Vite only exposes environment variables prefixed with `VITE_` to client code. Never store backend private keys, database credentials, or secret tokens in this repository.

## 6. Deployment Guides

### A. Cloudflare Pages (Recommended)
1. Push your code to your **GitHub** repository.
2. In the **Cloudflare Dashboard**, navigate to **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
3. Select the repository and branch (`main`).
4. Configure the build settings:
   * **Framework preset:** `Vite`
   * **Build command:** `npm run build`
   * **Build output directory:** `dist`
   * **Root directory:** `/`
5. Click **Save and Deploy**.
6. The `public/_redirects` file included in this repo will automatically handle SPA routing (`/* /index.html 200`).

---

### B. Vercel
1. In your **Vercel Dashboard**, click **Add New...** > **Project** and import your GitHub repository.
2. Vercel will automatically detect `Vite`.
3. Set:
   * **Build Command:** `npm run build`
   * **Output Directory:** `dist`
4. Deploy. The included `vercel.json` ensures direct route navigations (`/about`, `/treatments/:slug`, etc.) resolve to `/index.html` with optimal cache-control headers.

---

### C. Netlify
1. Log into **Netlify** and select **Add new site** > **Import an existing project** > **GitHub**.
2. Set:
   * **Build command:** `npm run build`
   * **Publish directory:** `dist`
3. Deploy. The `public/_redirects` file ensures seamless SPA routing.

## 8. Client Handoff & Maintenance Guide

All clinic copy and media are centralized in `src/data/` for easy updates:

### Modifying Clinic Info & Working Hours
* Edit `src/data/site.ts`
* Update phone numbers, WhatsApp, clinic address, timings, or Dr. Pruthvi Vaity's biography.

### Adding or Modifying Treatments
* Edit `src/data/treatments.ts`
* Each treatment defines its `slug`, `title`, `tagline`, `benefits`, `process`, `whatToExpect`, and FAQs.

### Updating Imagery & Photography
* Edit `src/data/assets.ts`
* Swap Unsplash placeholders for official clinic photos, interior suites, or before/after case studies.
* Images gracefully fallback to the HealRx luxury monogram placeholder if any link ever fails.

### Managing SEO & Sitemap
* `public/sitemap.xml`: Update if new top-level or procedure pages are added.
* `public/robots.txt`: Directs search engines to crawl indexable pages.
* `src/components/seo/SEOHead.tsx`: Injects dynamic canonical links, Open Graph images, and descriptions per page.
